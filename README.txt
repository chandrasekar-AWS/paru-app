PARU - build and install
1) Upload this folder to a PRIVATE GitHub repo (env.txt and agent.db are never uploaded).
2) GitHub -> Actions -> "Build Windows app" -> when green, download the Paru-Setup artifact, unzip, run Paru Setup.exe.
3) Open Paru -> Settings (address http://localhost:8000, your VOICE_KEY) -> Keys (fill env.txt) -> Save.
4) Say "hello Paru" or press Ctrl+Shift+Space.
