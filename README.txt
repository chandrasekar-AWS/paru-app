Paru 2.2
- Say "hello Paru" (any language). Orb appears top-right and stays until you say "shut up" / "stop".
- Ctrl+Shift+Space starts or ends a conversation.
- Settings has everything: General, Voices, Voice recognition, Permissions, Assistant, Keys, Customize.
- After updating agent.py run:  pip install -r agent\requirements.txt
- In agent\env.txt set REPORT_HOUR=17 (daily report 5 PM to 5 PM) and optionally CALENDAR_ICS_URL=<secret iCal link>.
